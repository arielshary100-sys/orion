# ORION

עוזר קולי אישי בעברית עם ליבה הולוגרפית.

**האתר:** https://arielshary100-sys.github.io/orion/

לוחצים "הפעל מערכת", מאשרים מיקרופון ואומרים "היי".

## מה הוא יודע
- שיחה, שם שאפשר לשנות ("קוראים לך מקס")
- שעה, תאריך, טיימרים ותזכורות
- מזג אוויר להיום ולמחר
- שירים ביוטיוב, פתיחת אתרים, חיפוש בגוגל
- משחקים: חידות, טריוויה, נחש מספר, תרגילי חשבון
- תרגום לאנגלית
- זיכרון ("תזכור שאני אוהב פיצה")
- החלפת צבע ("תחליף צבע לאדום")
- מילת הפעלה: עונה רק כשאומרים את השם שלו
